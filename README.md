Data analysis portfolio: four projects that turn raw data into clear answers and recommendations. Built with Python, SQL and Power BI.

By **Shahd Elhassan**, A junior data analyst | [LinkedIn](https://www.linkedin.com/in/shahd-elhassan-09b7b03a4)

| Project | Key finding | Tools |
|---|---|---|
| [Superstore Sales and Profit Analysis](./Superstore_Sales_Analysis) | Order lines discounted above 20% lost $135.4K, 47% of total profit. Recommended testing a 20% discount cap. | Python, Power BI (DAX) |
| [Olist E-commerce: Funnel, Cohort and Retention Analysis](Olist_Funnel_Cohort_Retention_Analysis) | Only 3.04% of customers order twice (2.15% excluding likely split orders). Reviews, delivery, category and location explain little, so recommended a controlled retention test. | SQL (SQLite) |
| [Customer Segmentation (RFM and K-Means)](./Customer_Segmentation_Analysis) | The top segment, 30.3% of customers, drives 80.7% of spending. One recommended action per segment. | Python, scikit-learn |
| [Google Play Store Market Analysis](./Google_Play_Store_Analysis) | Education is the strongest all-round category. 7 apps hold 52.2% of the minimum paid-app revenue estimate. | Python, Plotly, VADER |


Each folder has its own README with the data source, method, results and how to run it.
